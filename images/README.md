# Project thumbnails

Drop the three project screenshots in this folder with these **exact** filenames
(referenced by `index.html`):

| File | Project |
|---|---|
| `rainydays.jpg` | Rainydays (Cross Course Project) |
| `hiking-project.jpg` | Hiking Project (Semester Project 1) |
| `project-exam-1.jpg` | Project Exam 1 |

## Assignment requirements for each thumbnail

- Format: **PNG or JPEG** (these filenames use `.jpg`; if you save PNGs, rename the
  `src` in `index.html` to `.png`).
- **Optimised to ≤ 200 KB each.**
- Recommended size: around **600 × 400** px (matches the card layout).

## How to optimise

1. Take a screenshot of each live project.
2. Resize to ~600 × 400 px.
3. Compress with a tool like [squoosh.app](https://squoosh.app) or
   [tinypng.com](https://tinypng.com) until the file is under 200 KB.
4. Save into this folder using the filename from the table above.

Until real images are added, the cards will show a broken-image icon.
